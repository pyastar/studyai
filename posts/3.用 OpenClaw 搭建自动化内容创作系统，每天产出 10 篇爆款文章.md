### 第 2 步：配置热点监测

创建热点监测技能 `~/skills/content-creator/hot-topics/skill.json`:

```json
{
  "name": "热点自动监测",
  "description": "每 2 小时监测全网热点话题",
  "trigger": {
    "type": "schedule",
    "cron": "0 */2 * * *"
  },
  "actions": [
    {
      "type": "web_search",
      "query": "今日热点 热搜榜",
      "sources": ["weibo", "zhihu", "baidu"]
    },
    {
      "type": "ai_filter",
      "model": "qwen-plus",
      "prompt": "从以下热点中筛选适合创作的话题，标准：\n1. 有讨论度（热度>10000）\n2. 有争议性或实用性\n3. 适合写成 800-1500 字文章\n\n返回 Top 10 话题，格式：话题 | 热度 | 推荐理由"
    },
    {
      "type": "save",
      "format": "json",
      "path": "~/content/hot_topics_{{date}}.json"
    },
    {
      "type": "send_message",
      "channel": "dingtalk",
      "to": ["自己"],
      "content": "🔥 今日热点 Top 10 已生成，请查看 ~/content/hot_topics_{{date}}.json"
    }
  ]
}
```

**监测频率**:
- 每 2 小时更新一次
- 自动筛选高价值话题
- 推送到手机提醒

{

  "description": "根据选题自动生成文章",
  "trigger": {
    "type": "manual"
  },
  "actions": [
    {
      "type": "load_file",
      "path": "~/content/hot_topics_{{date}}.json"

    {
      "type": "ai_write",
      "model": "qwen-plus",
      "prompt": "根据以下话题写一篇爆款文章：\n\n【话题】{{topic}}\n【要求】\n1. 标题：吸引眼球，带数字或情绪词\n2. 开头：3 秒抓住读者注意力\n3. 正文：分 3-5 个小节，每节有金句\n4. 结尾：引导互动（点赞/评论/转发）\n5. 字数：800-1200 字\n6. 风格：口语化、有共鸣、易传播\n\n【输出格式】\n标题：xxx\n正文：xxx\n标签：#xxx #xxx #xxx"

### 第 4 步：配置自动配图

创建配图技能 `~/skills/content-creator/auto-image/skill.json`:

```json
{
  "name": "文章自动配图",
  "description": "根据文章内容生成封面图",
  "trigger": {
    "type": "after",
    "skill": "AI 自动写作"
  },
  "actions": [
    {
      "type": "load_file",
      "path": "~/content/drafts/{{topic}}_{{date}}.md"
    },
    {
      "type": "ai_extract",
      "model": "qwen-plus",
      "prompt": "从以下文章中提取封面图描述：\n1. 文章主题\n2. 核心情绪（积极/消极/中性）\n3. 适合的视觉元素\n\n返回英文提示词，格式：A [style] image showing [subject], [mood], [colors]"
    },
    {
      "type": "generate_image",
      "model": "dall-e-3",
      "prompt": "{{image_prompt}}",
      "size": "1024x1024"
    },
    {
      "type": "save",
      "format": "png",
      "path": "~/content/images/{{topic}}_{{date}}.png"
    }
  ]
}
```

**配图风格**:
- 小红书：9:16 竖图，鲜艳色彩
- 公众号：16:9 横图，简洁风格
- 知乎：1:1 方图，专业感

### 第 5 步：设置多平台发布

创建发布技能 `~/skills/content-creator/multi-publish/skill.json`:

```json
{
  "name": "多平台自动发布",
  "description": "一键发布到小红书/公众号/知乎",
  "trigger": {
    "type": "manual"
  },
  "actions": [
    {
      "type": "load_file",
      "path": "~/content/drafts/{{topic}}_{{date}}.md"
    },
    {
      "type": "load_file",
      "path": "~/content/images/{{topic}}_{{date}}.png"
    },
    {
      "type": "format_platform",
      "platform": "xiaohongshu",
      "template": "emoji_title + body + tags"
    },
    {
      "type": "format_platform",
      "platform": "wechat",
      "template": "markdown + cover_image"
    },
    {
      "type": "format_platform",
      "platform": "zhihu",
      "template": "markdown + topics"
    },
    {
      "type": "publish",
      "platform": "xiaohongshu",
      "account": "your-account",
      "schedule": "18:00"
    },
    {
      "type": "publish",
      "platform": "wechat",
      "account": "your-official-account",
      "schedule": "20:00"
    },
    {
      "type": "publish",
      "platform": "zhihu",
      "account": "your-zhihu",
      "schedule": "21:00"
    }
  ]
}
```

**发布时间策略**:
- 小红书：18:00（下班通勤时间）
- 公众号：20:00（晚饭后）
- 知乎：21:00（睡前）

## 💬 常见问题

### Q1: AI 写的文章有人味吗？

**A**: 完全可以！

**关键点**:
- 使用你写的模板（保持你的风格）
- 加入你的个人经历和案例
- AI 生成后人工审核修改（5 分钟/篇）

**建议**: AI 写初稿，你做润色，效率最高。

### Q2: 会被平台判定为 AI 内容吗？

**A**: 不会！

- 平台无法检测 AI 生成（无可靠检测方法）
- 关键是内容质量，不是生成方式
- 加入个人观点和案例，就是原创

### Q3: 一天 10 篇会不会质量下降？

**A**: 不会！

- 热点选题保证话题热度
- AI 模板保证内容结构
- 人工审核保证最终质量

**实际效果**: 爆款率从 5% 提升到 15%

### Q4: 多平台发布会被限流吗？

**A**: 不会！

- 各平台内容格式不同（自动适配）
- 发布时间错开（避免同时发布）
- 内容微调（平台专属标签）
