### 案例：电商客服自动化系统

#### 客户背景

**姓名**: 李总  
**行业**: 电商（天猫 + 拼多多）  
**规模**: 日咨询量 500+  
**痛点**: 
- 客服团队 8 人，人力成本 ¥60,000/月

- 夜间咨询无法及时响应，流失率 35%

#### 具体实现步骤

**第 1 步：安装 OpenClaw**

```bash
# 下载安装
curl -fsSL https://get.openclaw.ai | bash

# 启动服务
openclaw gateway start

# 验证安装
openclaw status
```

**第 2 步：配置 AI 模型**

编辑配置文件 `~/.openclaw/config.json`:

```json
{
  "model": {
    "provider": "dashscope",
    "api_key": "sk-xxxxx",
    "model": "qwen-plus"
  },
  "channels": {
    "dingtalk": {
      "enabled": true,
      "token": "your-dingtalk-token"
    }
  }
}
```

**第 3 步：创建客服技能**

创建文件 `~/skills/ecommerce-support/skill.json`:

```json
{
  "name": "电商客服助手",
  "description": "自动回复电商常见问题",
  "triggers": [
    "发货",
    "物流",
    "退换货",
    "优惠券",
    "发票"
  ],
  "actions": [
    {
      "type": "ai_reply",
      "template": "客服回复模板"
    },
    {
      "type": "human_handoff",
      "condition": "ai_confidence < 0.8"
    }
  ]
}
```

**第 4 步：配置知识库**

创建常见问题库 `~/skills/ecommerce-support/kb.md`:

```markdown
# 电商常见问题知识库

## 发货相关

**Q: 什么时候发货？**
A: 付款后 48 小时内发货，默认发中通快递

**Q: 可以指定快递吗？**
A: 可以，备注即可（顺丰到付）

## 退换货政策

**Q: 支持 7 天无理由退换吗？**
A: 支持，商品未使用不影响二次销售

**Q: 退换货运费谁承担？**
A: 质量问题我们承担，无理由退换买家承担

## 优惠券使用

**Q: 优惠券可以叠加吗？**
A: 店铺券可以和平台券叠加使用

**Q: 优惠券有使用门槛吗？**
A: 满 99 减 10，满 199 减 30
```

**第 5 步：设置人工转接**

配置转接规则 `~/skills/ecommerce-support/handoff.json`:

```json
{
  "handoff_rules": [
    {
      "condition": "contains(投诉)",
      "action": "notify_supervisor",
      "channel": "dingtalk"
    },
    {
      "condition": "ai_confidence < 0.7",
      "action": "create_ticket",
      "assign_to": "human_agent"
    },
    {
      "condition": "time_range(23:00-09:00)",
      "action": "auto_reply_with_delay",
      "message": "您好，当前是夜间服务时间，我们将在明早 9 点优先处理您的问题"
    }
  ]
}
```

**第 6 步：测试运行**

```bash
# 测试技能
openclaw skills test ecommerce-support

# 查看日志
tail -f ~/.openclaw/logs/support.log

# 上线运行
openclaw skills enable ecommerce-support
```
